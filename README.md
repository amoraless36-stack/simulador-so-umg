# SimuSO - Simulador de recursos de un sistema operativo

Proyecto final de Sistemas Operativos I (código 029), Universidad Mariano Gálvez de Guatemala.

## Módulos
- Planificador de CPU: FCFS, SJF y Round Robin con diagrama de Gantt
- Memoria RAM: First Fit, Best Fit y Worst Fit, con mapa de memoria
- Interbloqueos: algoritmo del banquero, grafo de recursos y condiciones de Coffman
- Concurrencia: condición de carrera, mutex y semáforos
- PCB y ciclo de vida de los procesos

## Requisitos
- JDK 21 o superior

## Cómo ejecutar
```
javac -encoding UTF-8 *.java
java Main
```
