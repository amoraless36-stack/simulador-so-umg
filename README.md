   # SimuSO - Simulador de recursos de un sistema operativo

   Proyecto final de Sistemas Operativos I (codigo 029), Universidad Mariano Galvez de Guatemala.

   ## Modulos
   - Planificador de CPU: FCFS, SJF y Round Robin con diagrama de Gantt
   - Memoria RAM: First Fit, Best Fit y Worst Fit
   - Interbloqueos: algoritmo del banquero
   - Concurrencia: condicion de carrera, mutex y semaforos
   - PCB y ciclo de vida de los procesos

   ## Requisitos
   - JDK 21 o superior

   ## Como ejecutar
   javac -encoding UTF-8 *.java
   java Main
